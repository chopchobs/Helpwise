## 🔴 ขอบเขต — อ่านก่อนใช้อ้างอิงทุกครั้ง

1. **รายการถูกตัดที่ 100 ใบ** — `--limit 100` คืนครบ 100 พอดี
   ⇒ **นี่ไม่ใช่ประวัติทั้งหมด มันคือ 100 ใบล่าสุด ณ เวลาที่ดึง**
   ⇒ ข้อความที่เขียนได้คือ **"ไม่พบ … ในหน้าต่างนี้"** ⛔ **ห้ามเขียนว่า "ไม่เคยมี"**
2. **วันไม่เต็ม:** `2026-08-09` (9 ใบ) และ `2026-08-14` (4 ใบ) ถูกตัดด้วยขอบหน้าต่าง
   ⛔ **ห้ามเอาไปเทียบกับวันเต็ม** (`08-10` … `08-13`)
3. **`startedAt == createdAt` ทั้ง 89 ใบ** — ⛔ **ห้ามใช้เป็นหลักฐานว่า "ไม่มีคิว"**
   อาจเป็นพฤติกรรมของ API เองสำหรับ event `schedule`
   ⇒ หลักฐาน "ไม่มีคิว" ใช้ **`updatedAt − createdAt`** (29–59s) คู่กับ
   **offset ที่จับคู่กับข้อความ Discord** (32–37s) ซึ่งเป็นสองแหล่งอิสระ
4. **ตรวจแล้วว่า commit ลง public repo ได้** (Dev ตัดสิน 2026-08-14) — JSON มีแค่
   `databaseId` · `event` · `status` · `conclusion` · เวลา 3 ฟิลด์ ⇒ **ไม่มี secret / ชื่อคน / log**
5. **retention ของ GitHub Actions = 90 วัน** ⇒ ไฟล์นี้เป็นสำเนาที่อยู่นอกระบบที่หมดอายุ
   (ตามกฎ §1 ของ incident: *หลักฐานที่หมดอายุ ต้องเก็บก่อนหลักฐานที่ไม่หมดอายุ*)
   ⇒ ⛔ **ห้ามลบไฟล์นี้** แม้ข้อ 2 จะปิดไปแล้ว
